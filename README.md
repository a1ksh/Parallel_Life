# Parallel Life

Қазақша интерактивті көркем ойын. Мансап пен кәсіп, оқу және қарым-қатынас сценарийлерінің әрқайсысында бір жағдайдан бірнеше жол тарайды. Екі жолды аяқтағанда финалдарды салыстырып, Decision Passport карточкасын сақтауға немесе жүктеуге болады.

Ойын барысы сол браузерде сақталады. Сюжеттер `public/scenarios.js` файлында.

## Іске қосу

Node.js 20.3+ қажет.

```sh
npm run build
npm run preview
```

Preview командасы тек әзірлеуге арналған. Онлайн жариялау үшін `npm run build` шығаратын `dist/server/index.js` файлы Cloudflare Worker ретінде іске қосылады. Сайтты қолдану үшін әзірлеушінің компьютері қосылып тұруы қажет емес.

## Қосымша интеграциялар

- `OPENAI_API_KEY` қосылғанда ойыншы мәтінге өз жағдайынан деталь қоса алады. `OPENAI_MODEL` арқылы модельді таңдауға болады.
- `IN8B_API_KEY` қосылғанда 1in8b Engine арқылы ойдан шығарылған кейіпкерді ашуға болады.

Кілттерді хостингтің серверлік құпияларына енгіз. Қосымша қызметтердің жауабы кешіксе, дайын сюжет жалғасады.
