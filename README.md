# Parallel Life

Бесплатная интерактивная игра о жизненных решениях на русском, казахском и английском. [Играть на Render](https://parallel-life-k7j1.onrender.com/ru/) · [Создать личную историю](https://parallel-life-k7j1.onrender.com/ru/personal/)

## Идея и цель проекта

Что, если остаться на привычной работе? А если брать собственные заказы, когда свободны только два вечера в неделю? В жизни трудно проверить оба пути одновременно. В Parallel Life можно прожить две вымышленные версии одной ситуации и сравнить, на что в каждой хватило времени, денег и сил.

Цель игры — помочь человеку сформулировать важный для него компромисс и придумать небольшой шаг для проверки в реальности. События в игре вымышлены. Показатели персонажа описывают правила сценария и не выражают вероятность будущего.

## Как играть

- **Личная история Gemini.** Введите два своих варианта и одно ограничение. Для каждого варианта Gemini создаёт отдельную сцену с двумя возможными действиями. Выберите действие, прочитайте его последствия, перейдите в соседнюю ветку и сравните. Можно указать личную цель. После подтверждения действия в финале появятся последствия и объяснение, удалось ли достичь цели. В каждой пройденной ветке можно спросить своё другое «я», почему оно приняло это решение. Диалог сохраняется отдельно для каждого варианта и действия. Откройте «Мои личные истории» в том же браузере, чтобы вернуться.
- **Готовые истории.** Выберите карьеру, учёбу или отношения. В каждой теме есть три стартовых пути. Создайте персонажа или воспользуйтесь быстрым стартом, затем пройдите пять сцен. На карте жизней можно вернуться к прежнему решению и создать независимую ветку.
- **После финала готовой истории.** Сравните, где разошлись две жизни и чем пришлось пожертвовать. Спросите другое «я», почему оно так поступило. Диалог опирается на события выбранной ветки. В лаборатории решений можно сохранить свои приоритеты в паспорте решения и наметить эксперимент на неделю.

## Игровой движок

В готовых историях сервер определяет доступную сцену по журналу решений. При выборе действия он проверяет номер сцены, сохраняет состояние перед решением и применяет изменения к показателям мира и доверию персонажей. Значения остаются в диапазоне от 0 до 100. Перед ходом видны изменения в очках. Игровая цель — закончить с минимумом 50 очков по каждому выбранному приоритету (по основному показателю сценария, если приоритеты не указаны). Финал показывает счёт по всем шести показателям. Например, достаточное доверие в третьей сцене открывает дополнительное действие. При возврате к развилке движок копирует сохранённое состояние в новую ветку. Исходный финал остаётся доступным для сравнения. [Код движка](backend/app/game_engine/__init__.py) · [Данные сценариев](backend/app/scenarios/)

Личные истории используют отдельный короткий цикл. Сервер отправляет Gemini варианты, ограничение и язык. Ответ содержит две сцены, четыре действия и четыре соответствующих последствия. Сервер проверяет структуру ответа и сохраняет его целиком. Поэтому выбор кнопки и повторное открытие уже созданной истории не требуют новой генерации. При недоступности Gemini черновик остаётся в браузере, а создание можно повторить. [API личных историй](backend/app/api/personal.py)

## Архитектура

| Компонент | Роль |
| --- | --- |
| [Next.js и React](frontend/) | Мобильный интерфейс, три языка, карта веток и экран личной истории. Статические страницы собираются при публикации. |
| [FastAPI](backend/app/api/) | Раздаёт API игры, проверяет владельца сохранения и обрабатывает выборы. В размещённом приложении статику и API обслуживает один сервис. |
| [Сервис генерации](backend/app/services/story.py) | Вызывает модель на сервере и проверяет ответ. Для личной истории используется Gemini. Готовые истории доступны и без модели. |
| [SQLAlchemy и база](backend/app/models/database.py) | PostgreSQL в Neon хранит игровые сессии, ветки, диалоги и личные истории. Для локального запуска используется SQLite. Гостевые сохранения привязаны к случайному токену браузера. |
| [Docker](Dockerfile) и [Render](render.yaml) | Первый этап собирает интерфейс, второй запускает FastAPI. Данные опубликованной игры хранятся отдельно от контейнера. |

## Запуск на своём компьютере

Понадобятся Python 3.11 или новее и Node.js 24. Выполните из корня репозитория:

```sh
npm ci --prefix frontend
npm run build
python -m venv .venv
```

Активируйте окружение командой `.venv\Scripts\Activate.ps1` в PowerShell или `source .venv/bin/activate` в Linux и macOS. Затем запустите сервер:

```sh
python -m pip install -r backend/requirements.txt
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Игра откроется по адресу [localhost:8000/ru/](http://localhost:8000/ru/), описание API — по адресу [localhost:8000/docs](http://localhost:8000/docs).

Для личных историй задайте на сервере `PARALLEL_LIFE_AI_PROVIDER=gemini` и `GEMINI_API_KEY`. Модель можно указать в `GEMINI_MODEL`. Локально настройки читаются из файла `.env` в корне проекта. На Render ключ хранится в Environment, а строка подключения Neon — в `PLAYER_DATABASE_URL`. Используйте тот же браузер и адрес сайта для доступа к прежним сохранениям.

## Проверка

После сборки выполните `npm run test:sites` в корне и `python -m pytest -q` в каталоге `backend` с активированным окружением. Для ручной проверки пройдите обе личные ветки, обновите страницу и откройте сохранённые решения. [Сценарий демонстрации готовых историй](DEMO-PILOT-RU.md)
